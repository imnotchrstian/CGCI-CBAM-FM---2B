System Testing

Prototype testing tool only. It runs on temporary copies of the data, never changes your real records, and is not a substitute for production security testing.

Privacy and Codenames

A codename is a pseudonym, not anonymity: this system stores each student's real name next to their codename, so the mapping is confidential. Keep it limited to authorized personnel. Student accounts only ever see their own records.

Data storage: This static demo saves data only in this browser's localStorage. It is not shared between users or devices, and anyone with access to this browser can read it. Do not store real student grades here.

For real use: use a backend with server-side authentication, hashed passwords, authenticated sessions, role-based access control, input validation, and prepared statements. Hidden HTML elements and client-side role checks cannot protect private data.
